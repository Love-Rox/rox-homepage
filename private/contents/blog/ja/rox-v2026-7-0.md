# Rox v2026.7.0 リリース

**Rox v2026.7.0** を安定版としてリリースしました！🎉

[v2026.7.0-rc](/blog/rox-v2026-7-0-rc) で導入した機能群が、RC 期間中の検証と修正を経て stable になりました。RC からの差分として、ツールチェーンと運用まわりの仕上げも入っています。

## RC からの新機能・改善

### 🧰 TypeScript 7.0.2 (stable) と依存パッケージの全面更新 (#260)

[6 月に TypeScript 7 (RC) へ移行](/blog/typescript-7-migration)していましたが、TypeScript 7 の正式リリースに追随し、**7.0.2 (stable)** へ更新しました。Go 製ネイティブコンパイラによる高速な型チェックを、正式版として全パッケージで利用しています。

あわせて依存パッケージを全面的に最新化しました。主なところでは:

- **waku** 1.0.0-beta.6 / **vite** 8.1.4
- **Lingui** 6.5 / **Sentry** 10.64 / **hono** 4.12.28
- ほか bullmq、sharp、Tailwind CSS など約 25 パッケージ

型エラー・テスト回帰ゼロでの更新です（バックエンド 1,000 件超のユニットテストと本番ビルドで検証済み）。

### 🏷️ ビルド識別情報の表示 (#250 / #253)

「いま動いているのはどのビルドか」を UI と API から確認できるようになりました。

- CI の実行番号に基づく **ビルド番号** と **コミット SHA** を `/api/instance` で返却
- フロントエンドにもビルド情報を表示し、`dev` チャネルではインジケーターを表示

継続的にデプロイされるインスタンスで、リリースの追跡がしやすくなります。

### 🚀 keel による自動デプロイ (#252)

RC で同梱した K3S マニフェストに、**keel による自動デプロイ構成**を追加しました。イメージタグのダイジェストをポーリングし、新しいイメージが公開されると自動でロールアウトします。RBAC（`keel-manage` Role）と `keel.sh/matchTag` によるタグ固定まで含めてあり、公式インスタンス（rox.love-rox.cc）もこの構成で運用しています。

### 🐛 細かな修正

- プロフィールページの「戻る」ボタンが確実に動作するように修正 (#251)
- モバイルデッキのスワイプをさらに滑らかに調整 (#248)
- K3S 構成で Prometheus が backend メトリクスを内部 NodePort 経由で収集できるように (#247)

## v2026.7.0 の主な機能（RC からの再掲）

- **時系列チャート統計サブシステム**: Misskey 互換の `GET /api/charts/*` と Admin ダッシュボード。既定はオフのオプトイン方式（`CHARTS_ENABLED=true`）で、TimescaleDB 拡張を検出すると hypertable・圧縮・保持ポリシーを自動適用します
- **デッキ操作性の刷新**: 表示時の横スライド不具合を修正し、モバイルの横スワイプをネイティブ CSS scroll-snap カルーセルへ置き換え
- **セルフホスター向け**: GHCR のコンテナイメージ（`ghcr.io/love-rox/rox-{backend,frontend}`）と K3S / Kubernetes マニフェスト一式

詳細は [RC のリリース記事](/blog/rox-v2026-7-0-rc)をご覧ください。

## アップデート方法

- **DB マイグレーション 0014 を含みます**（`chart_snapshots` テーブルの追加）。v2026.6.0 以前から更新する場合は `bun run db:migrate` を実行してください
- 破壊的変更はありません。チャート機能は既定でオフです

```bash
git pull origin main
bun install --frozen-lockfile
bun run db:migrate    # マイグレーション 0014 を適用
bun run build
```

コンテナ運用の場合は `ghcr.io/love-rox/rox-backend:v2026.7.0` / `ghcr.io/love-rox/rox-frontend:v2026.7.0` タグをご利用いただけます。
